satirical scrollytelling site for an "unnecessarily sophisticated cork coaster."

with audio + shot types), job `0c3aa40f`, and (2) manual 1 fps frame extraction
(166 frames) to read camera/motion arcs between beats.

### Extracted language
- **Camera choreography:** the *frame* is mostly locked; motion comes from the **product** (tilt, 3D rotate, 360° flip, descend-and-land) and from **scroll-coupled dolly/zoom** (slow dolly-in #12, zoom-to-edge #15, zoom-out #11). Reveal-through-motion, not cut-heavy coverage.
- **Lens behavior:** long-lens compression on product close-ups (shallow DOF, hard speculars); wide for establishing/editorial; rapid "digital zoom" used as a transition device.
- **Shot sequencing / pacing:** slow reverent product beats (3–13 s) punctuated by **bursts of fast glitch cuts** (#7) and frantic testimonial grids (#20) — tension/release. Roughly: hook → reverent hero → playful proof → technical credibility → configurator → CTA.
- **Transition logic:** scroll *is* the transition. Vertical scroll = descend/advance; horizontal galleries = filmstrip; digital zoom = scene change; pop-over window = modal. **No traditional UI chrome.**
- **Object entrances/exits:** product enters by **rising into frame / forming from a wireframe / descending from above**; exits by scale-out into the void or hand-off to a framed inset.
- **Motion arcs:** ease-heavy, weighty (the float has inertia + a "whoosh"); the 360° flip is a single confident arc, not a spin.
- **Depth cues:** deep warm-black negative space, volumetric key + colored rim, long cast shadows, **holographic ghost duplicates receding behind** the hero, parallax desk layers.
- **Lighting language:** warm amber/golden key, low-key on hero beats, colored gradient washes (purple/magenta on hover, red in configurator, blue thermal), bright naturalistic for "real life" desk shots.
- **Atmosphere / tone:** confident, deadpan-luxury, "unnecessarily sophisticated" reverence for a humble object; cinematic restraint with playful spikes.
- **Premium techniques:** monumental editorial type bleeding off-frame, framed/rounded media insets, fake-technical credibility (formulas, wireframe HUD, spec table, research paper), persistent hero product, reactive hover, sound design (whoosh/VO/beats).
- **Visual hierarchy:** product > monumental type > one accent color > supporting copy in small caps. One subject per screen.
